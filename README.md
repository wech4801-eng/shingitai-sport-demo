# Shingitai Sport — démo « style MetaMask »

Maquette de démonstration du site de l'app Shingitai Sport, inspirée de la mise en scène du site MetaMask
(intro animée, scène épinglée au scroll, grilles de cartes vivantes). Le site officiel reste
[shingitaisport.fr](https://shingitaisport.fr/).

Démo en ligne : https://wech4801-eng.github.io/shingitai-sport-demo/

## Lancer en local

```bash
npm install
npm run dev
```

## Publier

`npm run build` produit `dist/`, publié tel quel sur la branche `gh-pages` (GitHub Pages).

Stack : Vite, GSAP + ScrollTrigger, Lenis, Dela Gothic One, Manrope.
